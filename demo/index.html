web-kit demos

One page per module, for trying it in a real browser without any project. Each page imports the module straight from its folder in this repository, so it shows the branch you are on, not a release.

  • feedback-kit "Send feedback": a picture of an SVG to draw on, and a GitHub issue filled in with what was on screen.

Serve the repository's root, for example with python3 -m http.server, and open http://localhost:8000/demo/. Opened as a file, the browser won't load the modules. Online, at bremondr.github.io/web-kit/demo/, it shows main.
